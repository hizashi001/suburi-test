## 実機で分かった、後でゲーム性を高めるときのメモ（ヒデキ、2026-11-19）

- HPとSP（スタミナ）のゲージは、格闘ゲームのように一目で分かる見せ方にしたい
- ターンとターンの間に、10秒ほど次の4拍を考える時間（シンキングタイム）がほしい。戦略を練る楽しみのため
- ステップは「その拍の中で動いたか」で見ているので、ステップ右のあと中央へ戻るとステップ左になる。
  つまりステップ右を2回続けると画面の外へ出てしまう。制約として面白いかもしれない（敵から離れても意味がない、という理由付け）
